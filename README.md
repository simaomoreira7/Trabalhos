# Trabalhos

Bem-vindo(a) ao meu repositório de trabalhos.

Este repositório reúne os diferentes projetos, exercícios e trabalhos que tenho desenvolvido ao longo do meu percurso académico e de aprendizagem.

O objetivo deste repositório é organizar e disponibilizar os trabalhos que fui realizando nas várias disciplinas e áreas de estudo, permitindo acompanhar a minha evolução e os conhecimentos adquiridos.

## Conteúdo

Neste repositório poderão ser encontrados:
- Trabalhos práticos;
- Projetos académicos;
- Exercícios;
- Outros ficheiros relacionados com a minha aprendizagem.
